# vibrasense
VibraSense is a machine learning project focused on vibration data analysis and predictive modeling.

## Project Structure

- `data/` - Datasets
- `notebooks/` - Data exploration and experiments
- `src/` - Data processing and machine learning code
- `app/` - Application interface
- `models/` - Trained machine learning models

## Technologies

Python, NumPy, SciPy, Pandas, Scikit-learn, XGBoost, SHAP, FastAPI, Streamlit.

## Status

Project setup in progress.
